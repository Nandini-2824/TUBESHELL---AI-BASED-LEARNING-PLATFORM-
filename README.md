🎓 TubeShell - AI Based Learning Platform
📌 Project Overview

TubeShell is an AI-powered learning platform designed to transform video transcripts into structured and interactive learning material. The platform allows users to paste the transcript of any educational video, after which Artificial Intelligence automatically generates:

📝 AI Summarized Notes
❓ MCQ-Based Quiz (10 Questions)
🧠 Flashcards (10)
📊 Performance Dashboard

The system helps students learn faster, revise efficiently, and track their performance through quizzes and analytics.

🚀 Features

✅ AI Generated Summarized Notes
✅ Automatic MCQ Quiz Generation
✅ Instant Quiz Evaluation
✅ AI Generated Flashcards
✅ Student Performance Dashboard
✅ Interactive and User-Friendly Interface
✅ Fast Learning Content Generation

🧠 How It Works
User pastes the transcript of a YouTube or educational video.
The transcript is sent to the backend server.
AI processes the transcript using NLP and LLM techniques.
The system generates:
Structured Notes
10 MCQ Questions
10 Flashcards
Users attempt the quiz.
The platform evaluates answers instantly.
Dashboard displays:
Quiz Score
Correct/Incorrect Answers
Overall Performance
